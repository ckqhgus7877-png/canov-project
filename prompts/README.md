# CANOV 구현 및 검토 프롬프트

섹션별 개발 프롬프트를 저장합니다. 파일명은 `00-common-rules.md`, `01-data-and-permissions.md`처럼 실행 순서를 포함합니다.

각 프롬프트에는 기준 요구사항, 작업 범위, 데이터와 권한, 정상·예외 흐름, 완료 조건, 검사 및 결과 보고 형식을 포함합니다.

구현은 Codex가 주도합니다. 중요한 변경의 Claude 검토가 필요하면 Codex가 별도의 전달용 프롬프트를 작성하고 사용자가 전달·결과 회신합니다. 검토 프롬프트는 구현 프롬프트와 구분하고 변경 목적, 요구사항, 기준 버전, 관련 코드·변경 내역, 실제 검사 결과와 확인할 위험을 포함합니다. 상세 협업 절차는 `docs/planning/CANOV-development-tools-plan.md`를 따릅니다.
