# CANOV 상담 신청 개인정보 처리 안내 문구 초안 v0.1

작성일: 2026-09-20
상태: 1안(고객 요청 처리 고지안) 선택 후 보완 중인 기획 초안. **실제 공개 사용 금지**. 운영 주체 정보를 입력하고 법적 근거의 최종 적합성을 검토한 뒤 사용한다.

## 1. 아직 입력하지 않은 공개 필수 정보

- 운영자·사업자 명칭: `[운영 주체 명칭 입력 필요]`
- 개인정보 문의 전용 이메일: `[privacy@CANOV 보유 도메인 입력 필요]`
- 카카오톡·CS 보조 문의 경로: `[확정된 채널 주소 또는 안내 입력 필요]`
- 개인정보 처리방침 주소: `[공개 URL 입력 필요]`
- 처리방침 시행일: `[YYYY-MM-DD 입력 필요]`
- 문구 버전: `[운영 문구 버전 확정 필요]`

위 표식이 하나라도 남아 있으면 실제 개인정보를 받는 공개 신청 기능을 열지 않는다. 임의의 이름·번호로 대체하지 않는다.

## 2. 법적 근거 확정 전 주의

개인정보 보호법 제15조제1항제4호는 계약 체결 과정에서 정보주체의 요청에 따른 조치를 이행하는 데 필요한 개인정보 처리를 허용한다. 개인정보보호위원회의 개인정보 처리 통합 안내서는 이 범위의 개인정보에 별도 동의를 요구하지 않고 처리 내용을 명확히 고지하는 방식을 안내한다.

CANOV는 1안을 기획 기준으로 선택했다. 공개 전 실제 상담·계약 흐름이 이 근거에 해당하는지 최종 검토하며 아래 두 안을 동시에 화면에 사용하지 않는다.

## 3. 1안 — 고객 요청 처리 고지안

현재 공식 안내를 반영해 선택한 기획안이다. 필요한 정보를 신청 전에 명확히 보여주되 필수 동의 체크박스를 두지 않는다.

### 화면 핵심 문구

#### 상담 신청을 위한 개인정보 처리 안내

`[운영 주체 명칭 입력 필요]`는 서비스 가능 여부 확인과 상담 신청 처리를 위해 아래 개인정보를 처리합니다.

| 구분 | 내용 |
|---|---|
| 처리 목적 | 서비스 가능 여부 확인, 상담 연락, 상담 신청 처리 |
| 처리 항목 | 이름, 휴대전화번호, 아파트 또는 지역, 차량 모델·차량 구분, 연락 희망 방식 |
| 보유·이용기간 | 상담 종료 또는 신청 철회 시 지체 없이 파기. 미응답·미계약 신청은 신청 접수일 또는 고객의 마지막 의미 있는 응답일로부터 최대 90일 보관 후 파기 |

계약으로 전환되면 계약과 서비스 이행에 필요한 최소 정보만 별도 계약 기록으로 이전하고 신청 원본의 중복 개인정보는 이전 확인 후 파기합니다. 자세한 내용은 `[개인정보 처리방침 링크 입력 필요]`에서 확인할 수 있습니다. 개인정보 관련 문의는 `[privacy@CANOV 보유 도메인 입력 필요]`로 접수할 수 있으며 `[확정된 카카오톡·CS 보조 경로 입력 필요]`도 이용할 수 있습니다.

버튼 문구: `상담 신청하기`

버튼 선택은 고객이 상담 처리를 요청하는 행위이며 마케팅 수신 동의로 해석하지 않는다.

## 4. 참고 대안 — 수집·이용 동의안

현재 선택하지 않은 참고 대안이다. 최종 검토에서 고지안의 근거가 적합하지 않다고 판단되거나 처리 흐름이 변경될 때만 다시 검토한다.

### 화면 핵심 문구

#### [필수] 상담 신청을 위한 개인정보 수집·이용 동의

`[운영 주체 명칭 입력 필요]`는 아래와 같이 개인정보를 수집·이용합니다.

| 구분 | 내용 |
|---|---|
| 수집·이용 목적 | 서비스 가능 여부 확인, 상담 연락, 상담 신청 처리 |
| 수집 항목 | 이름, 휴대전화번호, 아파트 또는 지역, 차량 모델·차량 구분, 연락 희망 방식 |
| 보유·이용기간 | 상담 종료 또는 신청 철회 시 지체 없이 파기. 미응답·미계약 신청은 신청 접수일 또는 고객의 마지막 의미 있는 응답일로부터 최대 90일 보관 후 파기 |

귀하는 개인정보 수집·이용 동의를 거부할 권리가 있습니다. 다만 위 정보는 상담 신청 처리에 필요한 정보이므로 동의하지 않으면 온라인 상담 신청을 접수할 수 없습니다.

체크박스 문구: `위 개인정보 수집·이용에 동의합니다. (필수)`

계약 전환 시 처리와 문의 방법은 `[개인정보 처리방침 링크 입력 필요]`에서 확인할 수 있게 한다.

## 5. 선택한 고지안에 적용할 기준

- 첫 공개 버전에는 마케팅 수신 동의를 표시하거나 수집하지 않는다.
- 차량번호, 상세 주차 위치, Care Profile, 보충 항목별 동의와 결제정보를 첫 상담 신청에서 받지 않는다.
- 필수 동의 체크박스와 개인정보 수집·이용 동의값을 만들지 않는다.
- 동의한 것처럼 기록하지 않고 신청 시점에 적용된 안내 문구 버전과 안내 시각을 기록한다.
- 펼쳐보기에는 화면 핵심 문구와 같은 항목·목적·기간이 들어가야 하며 서로 다른 값을 표시하지 않는다.
- 실제 저장 위치와 외부 처리업체가 확정되면 처리위탁·국외 처리 또는 이전에 관한 처리방침 기재 필요성을 별도로 검토한다.
- 공개 전 운영 정보, 보유기간 자동 파기, 처리방침, 화면 문구와 서버 기록이 일치하는지 확인한다.

- [ ] 운영자·사업자 명칭 입력
- [ ] CANOV 보유 도메인의 개인정보 역할 주소와 업무용 메일함 개설
- [ ] 도메인·메일 관리자, 결제·갱신·복구 권한을 운영 인수자에게 설정
- [ ] 다중 인증과 SPF·DKIM·DMARC 등 메일 인증 설정 확인
- [ ] 개인정보 역할 주소의 수신·회신 테스트
- [ ] 카카오톡·CS 보조 문의 경로 확정·수신 테스트
- [ ] 개인정보 처리방침 공개 주소와 시행일 입력
- [ ] 실제 저장 지역과 개인정보 처리 수탁자 확인
- [ ] 마케팅 동의가 포함되지 않았는지 확인
- [ ] 모바일·키보드·화면 읽기 도구로 안내 내용을 확인
- [ ] 법률 또는 개인정보 전문가의 최종 검토 필요성 판단
